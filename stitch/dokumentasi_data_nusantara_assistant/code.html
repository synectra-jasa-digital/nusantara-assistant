Pengenalan dan Instalasi

Data Nusantara Assistant menyediakan API komprehensif untuk mengakses data cuaca, finansial, demografi, dan wilayah di Indonesia. Panduan ini akan membantu Anda mengintegrasikan layanan kami.

bolt Mulai Cepat

Instal SDK resmi kami menggunakan npm atau yarn. SDK ini menangani autentikasi dan menyediakan tipe yang kuat (strongly-typed) untuk TypeScript.

Terminal 
npm install @datanusantara/sdk
# or
yarn add @datanusantara/sdk

Tinjauan API Endpoint

Beberapa endpoint bersifat publik, sementara yang lain (seperti data BPS detail) memerlukan API Key yang valid.
