Pengenalan dan Instalasi

Panduan memulai cepat untuk mengintegrasikan Data Nusantara Assistant ke dalam proyek Anda.

rocket_launch

Mulai Cepat

Instal paket inti menggunakan manajer paket pilihan Anda:

npm install @data-nusantara/core
# atau
yarn add @data-nusantara/core

Parameter Global

Parameter ini dapat digunakan di sebagian besar endpoint.

region_id String Required*

Kode unik wilayah (Provinsi/Kabupaten/Kota) sesuai standar Kemendagri.

limit Integer Optional

Jumlah data maksimal yang dikembalikan. Default: 10, Max: 100.
